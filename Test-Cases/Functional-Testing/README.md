# Functional Testing

This section contains functional test cases created to verify that application features behave according to expected requirements.

Functional testing is one of my primary areas of practical experience through crowdtesting and independent QA practice.

## Skills Demonstrated

- Requirement analysis
- Positive testing
- Negative testing
- Boundary testing where applicable
- Test scenario identification
- Test case design
- Test execution
- Expected versus actual result validation
- Defect identification

## Test Case Template

| Field | Description |
|---|---|
| Test Case ID | Unique identifier for the test case |
| Title | Brief description of what is being tested |
| Test Type | Functional |
| Priority | High / Medium / Low |
| Preconditions | Conditions required before execution |
| Test Data | Data required for the test |
| Steps | Actions required to execute the test |
| Expected Result | Expected application behaviour |
| Actual Result | Observed behaviour during execution |
| Status | Pass / Fail / Blocked / Not Run |
