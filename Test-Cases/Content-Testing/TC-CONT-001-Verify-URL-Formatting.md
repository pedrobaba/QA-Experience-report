# TC-CONT-001 — Verify URL Formatting

## Test Information

| Field | Details |
|---|---|
| Test Case ID | TC-CONT-001 |
| Source | Anonymized crowdtesting experience |
| Application Type | Web Application |
| Test Type | Content / Functional Validation |
| Priority | Medium |
| Execution Status | Executed |

## Objective

Verify that URLs displayed by the application are correctly formatted and do not contain unintended characters.

## Preconditions

- The application is accessible.
- A URL is displayed within the application.

## Test Steps

1. Open the relevant page.
2. Locate the displayed URL.
3. Review the URL format.
4. Check for unintended characters, spaces or punctuation.
5. Open the URL where applicable.
6. Verify that it leads to the intended destination.

## Expected Result

The URL should be correctly formatted and should navigate to the intended destination without errors.

## Evidence

Evidence was collected during testing. Confidential screenshots and application information are not publicly included.

## Learning / Improvement

Content-related issues can affect functionality and user experience. URL formatting should be validated as part of content and navigation testing.
