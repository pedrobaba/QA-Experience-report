# Exploratory Testing

This section documents exploratory testing activities using test charters and session notes.

Unlike scripted testing, exploratory testing combines learning, test design and test execution. The tester investigates the application and adapts testing based on observed behaviour and potential risks.

## Skills Demonstrated

- Application exploration
- Risk identification
- Dynamic test design
- Functional investigation
- Negative testing
- Defect discovery
- Evidence collection

## Exploratory Test Charter Template

| Field | Details |
|---|---|
| Charter ID | Unique identifier |
| Area Under Test | Feature or application area |
| Testing Goal | What the session aims to investigate |
| Duration | Planned or actual session duration |
| Test Approach | Areas and behaviours explored |
| Findings | Defects or observations discovered |
| Evidence | Screenshots, recordings or logs where permitted |
| Notes | Lessons or follow-up areas |

## Example Charter

**Charter ID:** ETC-001

**Area Under Test:** Product Search

**Testing Goal:**  
Explore search behaviour using valid, invalid, empty and unexpected inputs.

**Areas Explored:**

- Valid keywords
- Empty searches
- Special characters
- Long search terms
- No-result searches

**Outcome:**  
Document findings, unexpected behaviour, and areas requiring further testing.
