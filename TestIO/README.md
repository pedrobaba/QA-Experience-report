# TestIO Crowdtesting

This folder documents my experience on the TestIO platform. I participated in multiple test cycles involving web and mobile applications (functional and exploratory testing).  

- **Cycle Summary:** See `cycle-summary.md` for a table of test cycles, app types, and defect counts.  
- **Accepted Bugs:** `accepted-bugs/` contains example bug reports that were verified and accepted by TestIO.  
- **Rejected Bugs:** `rejected-bugs/` contains examples of rejected reports, with notes on lessons learned.  

> *Confidential information (client names, exact test URLs, screenshots of live products) have been anonymized according to TestIO guidelines.*
