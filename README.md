# QA Experience Report

## About This Repository

This repository documents my **hands-on Quality Assurance experience** as I transition from Frontend Development into a Junior QA Engineering role.

The purpose of this portfolio is to provide practical evidence of my ability to test software, identify and document defects, design and execute test cases, perform API testing, and communicate testing results clearly.

This is **not a learning-notes repository**. It is a curated record of practical QA activities, testing projects, crowdtesting experience, lessons learned, and professional testing documentation.

- **Test IO** — Participated in testing cycles and practiced defect identification and reporting.

## What This Repository Demonstrates

This portfolio is being built progressively to demonstrate my ability to:

- Understand testing requirements and scope
- Design meaningful test scenarios and test cases
- Execute positive and negative test scenarios
- Reproduce and document software defects
- Write clear and actionable bug reports
- Select appropriate evidence such as screenshots, screen recordings and logs
- Validate API responses and HTTP status codes
- Perform exploratory testing and investigate unexpected behaviour
- Learn from rejected defects and improve testing/reporting quality
- Document test execution and communicate testing results professionally
